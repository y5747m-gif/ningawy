# ننجاوي | NINJAWY

موقع متجر إلكتروني ثابت (Static Website) جاهز للنشر.

## الملفات
- index.html
- style.css
- script.js

## التشغيل
افتح index.html في المتصفح.

## النشر المجاني على Vercel
1. أنشئ حساب GitHub.
2. أنشئ Repository جديد باسم ninjawy.
3. ارفع الملفات الثلاثة إليه.
4. في Vercel اختر Add New Project ثم Import من GitHub.
5. اختر المستودع واضغط Deploy.

الموقع الحالي يستخدم بيانات منتجات تجريبية. يمكن لاحقًا ربطه بقاعدة بيانات ونظام طلبات ودفع.
