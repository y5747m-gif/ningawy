# ننجاوي | NINJAWY

متجر إلكتروني ثابت (Static Website) — بدون أي مكتبات خارجية، جاهز للنشر مباشرة.

A dependency-free static storefront, ready to deploy.

---

## ✨ المميزات | Features

| الميزة | التفاصيل |
|---|---|
| 🌍 **لغتان** | العربية (RTL) والإنجليزية (LTR) مع تبديل فوري وحفظ الاختيار، وترجمة كاملة تشمل أسماء المنتجات ورسالة واتساب ولوحة الإدارة |
| 🌗 **وضع داكن / فاتح** | نظام Design Tokens كامل لكل سمة، يتبع تفضيل النظام افتراضيًا ويُحفظ محليًا، بدون وميض عند التحميل (FOUC) |
| 🎨 **أيقونات جديدة** | مكتبة 60+ أيقونة SVG مرسومة على شبكة 24×24 بسماكة خط واحدة (1.5) وحواف دائرية متناسقة |
| 🌌 **خلفية متحركة** | 7 طبقات: تدرّج متحرك + شفق (Aurora) + شبكة + أشعة ضوئية + كانفس جسيمات ونجوم نينجا تتفاعل مع الماوس + شهب + ضوضاء |
| 🛒 **المتجر** | سلة مشتريات، مفضلة، بحث فوري، تصفية بالأقسام، عدّاد تنازلي للعروض، إتمام الطلب عبر واتساب |
| ✨ **حركة الإضافة للسلة** | صورة المنتج (أو أيقونته) تنطلق إلى منتصف الشاشة، ثم تطير بمسار منحني إلى السلة مع نبضة عند الوصول؛ تدعم تقليل الحركة والضغط المتكرر |
| 🔐 **لوحة إدارة** | تسجيل دخول، إضافة منتج (باللغتين + صورة + أيقونة + سعر قبل الخصم)، وحذف المنتجات |
| ♿ **إتاحة وأداء** | Skip link، تسميات ARIA، `prefers-reduced-motion`، أنماط طباعة، WebP للصور، وخطوط محسّنة |

## 📁 الملفات | Files

```
index.html                 الصفحة (تحتوي مكتبة الأيقونات مضمّنة inline)
style.css                  نظام التصميم: السمات + الاتجاهان + المكوّنات + الحركات
script.js                  المحرك: الترجمة، السمات، الخلفية، السلة، الإدارة
assets/icons/sprite.svg    مكتبة الأيقونات كملف مستقل (نفس الرموز المضمّنة)
assets/ninja-hero.webp     صورة البطل (محسّنة — 127KB)
assets/ninja-hero.png      نفس الصورة كاحتياطي للمتصفحات القديمة
vercel.json                إعداد Vercel: توجيه أي مسار غير موجود إلى index.html (لمنع خطأ 404)
```

## ▶️ التشغيل | Run

افتح `index.html` في المتصفح مباشرة، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 4173
# ثم افتح http://localhost:4173
```

## 🎛️ التحكم | Controls

- **اللغة:** مفتاح `ع / EN` في شريط التنقل (أو `localStorage.ninjawy_lang`).
- **السمة:** زر الشمس/القمر (أو `localStorage.ninjawy_theme`).
- **اختصار البحث:** `Ctrl/⌘ + K`.
- **لوحة الإدارة:** زر «الإدارة» — المستخدم `yaseen` وكلمة المرور `NINJAWY2026`
  (يمكن تغييرهما من أعلى `script.js`: `ADMIN_USERNAME` / `ADMIN_PASSWORD`).
- **رقم واتساب:** ثابت `WHATSAPP_NUMBER` في `script.js`.

## 🧩 بنية المنتج | Product shape

```js
{
  id: 1,
  category: "electronics",        // all | electronics | fashion | home | gaming | accessories
  icon: "headset",                // أي رمز من مكتبة الأيقونات
  price: 1299,
  oldPrice: 1699,                 // اختياري — يُظهر شارة الخصم %
  rating: 4.8,
  sold: 320,
  image: "",                      // DataURL أو رابط صورة (اختياري)
  ar: { name: "سماعات لاسلكية احترافية", desc: "..." },
  en: { name: "Pro Wireless Headphones", desc: "..." }
}
```

البيانات القديمة المحفوظة في `localStorage` تُرحَّل تلقائيًا إلى الصيغة الجديدة
(الأقسام العربية القديمة والأيقونات الإيموجي تُحوَّل إلى المفاتيح الحالية).

## ☁️ النشر المجاني على Vercel

1. أنشئ مستودع GitHub وارفع الملفات.
2. في Vercel اختر **Add New Project** ثم **Import** من GitHub.
3. اضغط **Deploy** — لا حاجة لأي إعدادات بناء (موقع ثابت).

> الموقع الحالي يستخدم بيانات منتجات تجريبية محفوظة في المتصفح.
> يمكن لاحقًا ربطه بقاعدة بيانات ونظام طلبات ودفع حقيقي.

## اختبار حركة السلة | Cart animation test

مع تشغيل الخادم المحلي على المنفذ `4173`، يمكن تشغيل اختبار المتصفح (Playwright أداة تطوير فقط، وليست اعتمادًا للموقع):

```bash
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/cart-flight.cjs
```

يغطي الاختبار الكمبيوتر والموبايل، مرحلتي الحركة، الضغط المتكرر، حفظ الكميات، تنظيف العناصر، تغيير حجم الشاشة، تقليل الحركة، والصور في الاتجاهين RTL وLTR.
يمكن تغيير عنوان الخادم عبر `CART_TEST_URL`، أو تحديد متصفح مثبت عبر `CHROMIUM_PATH`.
