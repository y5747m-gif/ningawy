# ساوند سوق | SOUND SOUQ

متجر إلكتروني ثابت وخفيف (Static Website) بهوية **ساوند سوق** — بدون مكتبات خارجية أو خطوط بعيدة، وجاهز للنشر مباشرة.

A dependency-free, lightweight static storefront. The same simple experience runs on every device, including low-end phones.

---

## ✨ المميزات | Features

| الميزة | التفاصيل |
|---|---|
| 🪶 **خفيف افتراضيًا** | بدون كانفس جسيمات، شفق، ضوضاء، شهب، مؤشر مخصص، Loader، WebGL، أو حركة طيران السلة |
| 🔤 **خطوط النظام** | لا يطلب Google Fonts أو أي موارد خارجية؛ العربية والإنجليزية بخطوط الجهاز |
| 🎨 **هوية ساوند سوق** | شعار SVG مستمد من الشعار المرفوع، ألوان العلامة المحددة، هيدر وفوتر داكنان، وواجهة فاتحة افتراضيًا |
| 🧊 **احترافي وخفيف** | مجسمات CSS ثلاثية الأبعاد ثابتة (مكعب/كرة/حلقة)، أشكال هندسية، ظلال صغيرة، بدون `backdrop-filter` أو حركات مستمرة |
| 🌍 **لغتان** | العربية (RTL) والإنجليزية (LTR) مع تبديل فوري وحفظ الاختيار |
| 🌗 **وضع داكن / فاتح** | الوضع الفاتح هو الافتراضي وفق الهوية، ويمكن تبديله للداكن ويُحفظ محليًا بدون وميض |
| 🛒 **المتجر** | سلة، مفضلة، بحث فوري، تصفية بالأقسام، عدّاد عروض بدقة الدقيقة، وإتمام الطلب عبر واتساب |
| ⚡ **تفاعل مباشر** | إضافة السلة وتحديث الكميات فورًا؛ قوائم المنتجات/السلة/الإدارة تستخدم تفويض الأحداث |
| 🖼️ **صور صغيرة** | صور المنتجات المرفوعة تُصغَّر إلى 640px وتُحفظ WebP/JPEG لتقليل مساحة التخزين والذاكرة |
| 🔐 **لوحة إدارة** | تسجيل دخول، إضافة منتج باللغتين مع صورة وأيقونة وسعر قبل الخصم، وحذف المنتجات |
| ♿ **إتاحة** | Skip link، تسميات ARIA، إدارة تركيز للنوافذ، دعم `prefers-reduced-motion`، وأنماط طباعة |

> المجسمات والأشكال مرسومة بـ CSS/SVG ثابتة؛ التفاعل البصري الوحيد هو رفع بسيط عند المرور بالمؤشر على الأجهزة الدقيقة، ويُلغى مع `prefers-reduced-motion`.
> العدّاد يعمل فقط عندما يكون قسم العروض ظاهرًا، وبفاصل دقيقة واحدة بدل تحديث كل ثانية.
> بيانات المنتجات والسلة محفوظة في `localStorage`؛ عند تعذر التخزين يظل المتجر يعمل في الذاكرة.

## 🎨 الهوية | Brand identity

الشعار الأصلي المرفق حُوّل إلى SVG خفيف للحفاظ على الحدة على كل الشاشات:

- `assets/sound-souq-mark.svg` — علامة S البرتقالية للأيقونة المفضلة favicon.
- `assets/sound-souq-logo.svg` — الشعار الكامل للنسخة الفاتحة.
- `assets/sound-souq-logo-white.svg` — الشعار الكامل للنسخة الداكنة، ويُستخدم في الفوتر بتحميل كسول.
- علامة الرأس والمكعب تستخدم رمزًا inline باسم `#i-brand` لتقليل الطلبات.

| اللون | الاستخدام |
|---|---|
| `#FF6B00` | البرتقالي الأساسي: الأزرار الرئيسية، الأسعار، CTA، الأيقونات النشطة، شارة «جديد» |
| `#E65F00` | البرتقالي الداكن عند المرور hover |
| `#111111` | الهيدر، الفوتر، النص الأساسي، زر إضافة للسلة، شارة «أصلي» |
| `#1A1A1A` | البطاقات الداكنة وقسم «لماذا ساوند سوق؟» |
| `#FFFFFF` | الخلفية الأساسية، النص على الداكن، بطاقات المنتجات |
| `#F5F5F5` | الأقسام المتبادلة، بطاقات الأقسام، خلفية قسم المنتجات |
| `#8A8A8A` | النصوص الثانوية والوصف وعدد المراجعات |
| `#E5E5E5` | الحدود الفاتحة |
| `#00C853` | متوفر في المخزون |
| `#E53935` | شارة الخصم والسعر القديم المشطوب |

> ملاحظة تباين: نص الأزرار البرتقالية أسود `#111` وليس أبيض، لأن الأبيض على `#FF6B00` منخفض التباين. الأسعار البرتقالية كبيرة وعريضة.

## 📁 الملفات | Files


## ▶️ التشغيل | Run

افتح `index.html` مباشرة، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 4173
# ثم افتح http://localhost:4173
```

## 🎛️ التحكم | Controls

- **اللغة:** مفتاح `ع / EN` في شريط التنقل (أو `localStorage.ninjawy_lang`).
- **السمة:** زر الشمس/القمر (أو `localStorage.ninjawy_theme`).
- **اختصار البحث:** `Ctrl/⌘ + K`.
- **لوحة الإدارة:** زر «الإدارة» — المستخدم `yaseen` وكلمة المرور الافتراضية `NINJAWY2026`
  (يمكن تغييرهما من أعلى `script.js`: `ADMIN_USERNAME` / `ADMIN_PASSWORD`).
- **رقم واتساب:** ثابت `WHATSAPP_NUMBER` في `script.js`.

### توافق البيانات القديمة

أُبقيت مفاتيح التخزين الداخلية `ninjawy_*` وكلمة المرور الافتراضية `NINJAWY2026` كما هي عمدًا حتى لا تفقد السلة/المفضلة/المنتجات/السمة/اللغة المحفوظة سابقًا. الاسم الظاهر للعلامة هو **ساوند سوق | SOUND SOUQ** فقط. غيّر كلمة المرور قبل النشر الفعلي.

## 🧩 بنية المنتج | Product shape

```js
{
  id: 1,
  category: "electronics",        // all | electronics | fashion | home | gaming | accessories
  icon: "headset",
  price: 1299,
  oldPrice: 1699,                 // اختياري
  rating: 4.8,
  sold: 320,                      // 0 => شارة «جديد»
  image: "",                      // DataURL أو رابط صورة (اختياري)
  ar: { name: "سماعات لاسلكية احترافية", desc: "..." },
  en: { name: "Pro Wireless Headphones", desc: "..." }
}
```

البيانات القديمة المحفوظة في `localStorage` تُرحَّل تلقائيًا
(الأقسام العربية القديمة والأيقونات الإيموجي تتحول إلى المفاتيح الحالية، وأيقونة `shuriken` القديمة تتحول إلى `sound`).

## ☁️ النشر المجاني على Vercel

1. ارفع الملفات إلى مستودع GitHub.
2. في Vercel اختر **Add New Project** ثم **Import** من GitHub.
3. اضغط **Deploy** — لا حاجة لأي إعدادات بناء.

> الموقع يستخدم بيانات منتجات تجريبية محفوظة في المتصفح.
> لوحة الإدارة الحالية للعرض فقط لأن بيانات الدخول تتحقق في المتصفح؛ الإنتاج الحقيقي يحتاج خادمًا ومصادقة.

## ✅ الاختبار | Test

مع تشغيل الخادم المحلي على المنفذ `4173`:

```bash
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/store-lite.cjs
```

يغطي الكمبيوتر والموبايل، عدم وجود طلبات خارجية أو حلقات حركة، وجود مشهد المجسمات الخفيف، التجاوب حتى 320px،
السلة والبحث وواتساب، اللغة والسمة، الإدارة وضغط الصور، تقليل الحركة،
ترحيل البيانات القديمة، والعمل عند تعطيل التخزين المحلي. كما يتحقق من ألوان الهوية الأساسية ووجود ملفات الشعار وشارات «أصلي/جديد» وحالة المخزون.
يمكن تغيير عنوان الخادم عبر `STORE_TEST_URL` أو تحديد متصفح عبر `CHROMIUM_PATH`.
